## Тема

Взаимодействие клиентского веб-приложения с внешним API.

## Цель работы

Освоить выполнение асинхронных HTTP-запросов средствами Fetch API, реализовать моковый сервер и авторизацию, связать пользовательский интерфейс из ЛР1 с серверными данными.

## Выбранный вариант

Вариант 5 — сервис для обмена рецептами и кулинарных блогов «Ложка».

## Реализация

Моковое API построено на `json-server` и `json-server-auth`. В `db.json` хранятся пользователи, рецепты, комментарии, избранное и подписки. Клиентский модуль `api.js` содержит общую функцию HTTP-запроса, добавляет JWT-токен в заголовок `Authorization` и преобразует сетевые ошибки в понятные сообщения.

Интерфейс получает из API:

1. подборку рецептов для главной страницы;
2. полный каталог и подробные данные отдельного рецепта;
3. комментарии к выбранному рецепту;
4. избранные рецепты авторизованного пользователя;
5. состояние подписок на авторов.

Регистрация выполняется маршрутом `POST /register`, вход — маршрутом `POST /login`. Полученные токен и профиль сохраняются в `localStorage`. Для изменения избранного, публикации комментария и управления подпиской требуется авторизация.

## Поиск и фильтрация

После получения каталога поиск выполняется по названию и ингредиентам. Результаты можно ограничить типом блюда, сложностью и максимальным временем приготовления. Для пустой выборки показывается отдельное состояние с подсказкой сбросить запрос.

## Обработка состояний

Для асинхронных разделов реализованы:

- индикатор загрузки;
- сообщение о недоступности API и кнопка повторной загрузки;
- состояние отсутствия данных;
- блокировка кнопок на время отправки запросов;
- toast-уведомления об успешных действиях и ошибках.

## Использованные технологии

- HTML5, CSS3 и Bootstrap 5.3;
- JavaScript и Fetch API;
- JSON Server;
- JSON Server Auth и JWT;
- Local Storage для хранения пользовательской сессии.

## Результат

Статический прототип из ЛР1 преобразован в клиент-серверное приложение. Содержимое и пользовательские действия синхронизируются с моковым API, а защищённые сценарии доступны после входа.
