# Лабораторная работа №2 — «Ложка»

Продолжение сервиса обмена рецептами из ЛР1. В этой версии данные загружаются через Fetch API из мокового API на базе JSON Server, а регистрация и вход выполняются через `json-server-auth`.

## Запуск

Требуется Node.js 18 или новее.

```bash
npm install
npm start
```

После запуска доступны:

- сайт: `http://localhost:8080`;
- API: `http://localhost:3000`;
- тестовый аккаунт: `maria@example.com`, пароль `recipe123`.

Важно: HTML-файлы нельзя открывать напрямую через `file://`, потому что браузер ограничивает запросы к API. Используйте адрес локального веб-сервера выше.

## Возможности

- регистрация и вход с получением JWT-токена;
- загрузка рецептов и подробной страницы рецепта через `fetch`;
- поиск по названию и ингредиентам, фильтры по типу, сложности и времени;
- добавление и удаление рецептов из избранного;
- личная коллекция авторизованного пользователя;
- загрузка и публикация комментариев;
- подписка и отписка от авторов;
- состояния загрузки, ошибки API и пустого результата.

## API

Основные маршруты:

```text
POST   /register
POST   /login
GET    /recipes
GET    /recipes/:id
GET    /comments?recipeId=:id
POST   /comments
GET    /favorites?userId=:id
POST   /favorites
DELETE /favorites/:id
GET    /follows?userId=:id
POST   /follows
DELETE /follows/:id
```

Данные для мокового сервера находятся в `db.json`, а права доступа — в `routes.json`: рецепты и комментарии можно читать без входа, изменение пользовательских коллекций требует JWT-токен. Адрес API задаётся в `assets/js/api.js`.
