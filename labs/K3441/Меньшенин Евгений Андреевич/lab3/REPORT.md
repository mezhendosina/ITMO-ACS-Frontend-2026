# Отчёт по лабораторной работе №3

**Тема:** разработка одностраничного веб-приложения с использованием Vue.js  
**Выполнил:** Меньшенин Евгений Андреевич  
**Группа:** K3441

## Цель работы

Мигрировать ранее созданный сервис обмена рецептами «Ложка» на Vue 3, применив компонентный подход, клиентскую маршрутизацию, composable-функции и работу с внешним API через axios.

## Выполнение

Проект создан на Vue 3 и Vite. Все пользовательские экраны стали маршрутами Vue Router: главная, каталог, рецепт, сообщество, вход, регистрация, профиль и страница 404. Защищённый профиль недоступен без авторизации, а страницы входа и регистрации не показываются уже вошедшему пользователю.

Повторяющиеся части интерфейса вынесены в компоненты: шапка, карточка и сетка рецептов, формы авторизации, состояния API. Логика разделена на composable-функции `useAuth`, `useFavorites` и `useApiState`. Экземпляр axios автоматически добавляет JWT-токен к защищённым запросам и преобразует сетевые ошибки в понятные сообщения.

Моковый API работает через `json-server-auth`. Реализованы получение списка и деталей рецептов, регистрация, вход, избранное, комментарии и подписки. Данные хранятся в `db.json`, а правила доступа — в `routes.json`.

## Проверенные сценарии

1. Загрузка главной страницы и каталога из API.
2. Поиск и совместное применение фильтров.
3. Переход к рецепту по динамическому маршруту.
4. Вход тестового пользователя и получение JWT.
5. Открытие защищённого профиля и загрузка избранного.
6. Добавление/удаление избранного, публикация комментария, подписка/отписка.
7. Отображение загрузки, ошибок API и пустой выдачи.
8. Создание production-сборки командой `npm run build`.

## Вывод

В результате статическое приложение из ЛР1–ЛР2 преобразовано в полноценное SPA на Vue 3. Применены Vue Router, axios, компоненты и composable-функции, а все основные сценарии продолжают работать с автономным API.
