# Лабораторная работа №3 — «Ложка»

Одностраничное приложение для обмена рецептами, перенесённое с HTML/JavaScript на Vue 3. Проект использует Vue Router, axios, Vite и автономный моковый API на JSON Server с JWT-авторизацией.

**Студент:** Меньшенин Евгений Андреевич  
**Группа:** K3441

## Запуск

Требуется Node.js 20.19+ или 22.12+.

```bash
npm install
npm start
```

После запуска доступны:

- приложение: `http://127.0.0.1:5173`;
- API: `http://localhost:3000`;
- тестовый аккаунт: `maria@example.com`, пароль `recipe123`.

Production-сборка и её просмотр:

```bash
npm run build
npm run api
# в другом терминале
npm run preview
```

Preview откроется на `http://127.0.0.1:4173`.

## Возможности

- SPA-маршрутизация без перезагрузки страницы;
- каталог, полнотекстовый поиск и фильтры;
- подробная страница рецепта;
- регистрация и вход с JWT;
- защищённый маршрут профиля;
- избранные рецепты, комментарии и подписки;
- состояния загрузки, ошибки и пустого результата;
- адаптивная вёрстка для мобильных и настольных экранов.

## Архитектура

- `src/views` — страницы приложения;
- `src/components` — повторно используемые интерфейсные компоненты;
- `src/composables` — состояние авторизации, избранного и общий жизненный цикл API-запросов;
- `src/services/api.js` — настроенный экземпляр axios с JWT-interceptor;
- `src/router` — карта маршрутов и navigation guards;
- `db.json`, `routes.json` — данные и правила доступа мокового API.

Ключевые API-маршруты: `/register`, `/login`, `/recipes`, `/comments`, `/favorites`, `/follows`.
