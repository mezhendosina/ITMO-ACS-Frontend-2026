# Лабораторная работа №1 — «Ложка»

Адаптивный многостраничный сайт сервиса обмена рецептами и кулинарных блогов. Выполнен на HTML, CSS, Bootstrap 5 и JavaScript без сборщика.

## Запуск

Откройте `index.html` в браузере. Для загрузки Bootstrap, иконок и шрифтов требуется интернет-соединение.

## Страницы

- `index.html` — главная страница;
- `search.html` — каталог с поиском и фильтрацией;
- `recipe.html` — подробная страница рецепта и комментарии;
- `profile.html` — личный кабинет, сохранённые рецепты и публикации;
- `community.html` — лента, лайки и подписки;
- `login.html` и `register.html` — вход и регистрация.

## Интерактивность

Фильтрация карточек без перезагрузки, проверка форм, добавление комментариев, сохранение рецептов, подписка на авторов, модальные окна, вкладки и уведомления Bootstrap.
