# Отчёт по лабораторной работе №1

**Выполнил:** Меньшенин Евгений Андреевич  
**Группа:** K3441

## Тема

Вёрстка сайта средствами HTML, CSS и Bootstrap.

## Цель работы

Разработать адаптивный интерфейс сервиса обмена рецептами и кулинарных блогов, освоить семантическую HTML-разметку, возможности CSS, сетку и компоненты Bootstrap, а также обработку пользовательских событий на JavaScript.

## Выбранный вариант

Вариант 5 — сервис для обмена рецептами и кулинарных блогов.

## Реализованные страницы

1. Главная страница с описанием сервиса и подборкой рецептов.
2. Вход в аккаунт.
3. Регистрация пользователя.
4. Личный кабинет с сохранёнными рецептами, публикациями и черновиками.
5. Каталог с поиском и фильтрацией по типу блюда, сложности и времени.
6. Страница рецепта с ингредиентами, инструкциями, автором и комментариями.
7. Лента сообщества с публикациями, подписками и тематическими тегами.

## Использованные технологии

- HTML5: семантические элементы `nav`, `main`, `section`, `article`, `aside`, `footer`, формы и подписи полей;
- CSS3: переменные, Grid/Flexbox, адаптивные медиазапросы, состояния наведения и пользовательская цветовая схема;
- Bootstrap 5.3: адаптивная сетка, навигация, формы, вкладки, модальные окна и toast-уведомления;
- JavaScript: фильтрация каталога, проверка форм, избранное, подписки и добавление комментариев;
- Bootstrap Icons и Google Fonts;
- собственное изображение главного экрана, созданное для проекта.

## Адаптивность

Интерфейс рассчитан на смартфоны, планшеты и настольные компьютеры. На узких экранах навигация сворачивается, карточки перестраиваются в одну колонку, фильтры переходят над каталогом, а формы занимают доступную ширину.

## Проверка требований

- обязательные страницы входа, регистрации, личного кабинета и поиска реализованы;
- дополнительные страницы рецепта и социальных функций реализованы;
- Bootstrap подключён и использован для сетки и интерактивных компонентов;
- пользовательские сценарии дополнены JavaScript;
- сайт связан внутренней навигацией и не требует сборки.

## Вывод

В ходе работы создан законченный прототип многостраничного веб-сервиса. Были применены основные приёмы адаптивной и семантической вёрстки, компоненты Bootstrap и обработка событий средствами JavaScript.
